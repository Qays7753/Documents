## Notes on the contract corpus

- `docs/contracts/` contains **35 files** because numbers 18–23 are used **twice** (a local
  product line and a network expansion line). This matrix keys on filenames, never numbers.
- Contract status hints inside the files lag in places: contract 11 is marked DRAFT while the
  inventory module is fully implemented and tested; local contracts 18*/19*/20* are marked
  DRAFT (PR review pending) while their code is merged with green CI. These are documentation
  staleness gaps (GAP-04), not missing features.
- The two pre-existing traceability artifacts (`docs/implementation-traceability.md` and
  `docs/implementation/02-domain-contract-coverage.md`) remain the in-repo ledgers; this atlas
  cross-references them and adds the journey/permission/entity dimensions.
