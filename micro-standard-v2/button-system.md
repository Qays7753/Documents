# Button System

The warm-ink primary is the single text-bearing commitment action in a context. Secondary uses the neutral tint. Outline and ghost reduce visual weight. Clay is reserved for identity/create/FAB and chosen/current edges. Destructive uses the error role with words and an icon.

All buttons use a 48px minimum height, 12px control radius, visible focus, duplicate-submit protection, loading without layout shift, and quiet completion.
