# Data Display System

Direct values come first. Numeric hierarchy is 30/20/15, amounts are end-aligned and bidi-isolated, and rows use a stable trailing amount slot. Relationship bars appear only when parts genuinely sum to a whole.

Charts are simple and question-led. Semantic colors show outcome or category; black is not the default for every series. A chart must have a readable label and a text alternative when the visual comparison matters.
