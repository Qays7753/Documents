# ZAI Flash Comparative Review — Current Inputs

هذا المجلد يحتوي أحدث مواد المراجعة فقط. الغرض منه دعم مراجعة read-only من ZAI Flash، وليس تنفيذ أي تعديل.

## المصادر الحية والمستودعات

- Micro Live: https://micro-prototype.pages.dev/setup
- Micro repository: https://github.com/Qays7753/Micro
- Accounting repository: https://github.com/Qays7753/Accounting
- Micro Standard v2: https://github.com/Qays7753/Documents/tree/main/micro-standard-v2

## ما يقرأه الوكيل من هذا المجلد

يقرأ الوكيل نتيجة Prototype v0 الأخيرة، النقد الذاتي، التحقق، قائمة المشكلات، الملاحظات الحية، وملخص نطاق المراجعة. هذه الملفات تمثل آخر نتيجة مراجعة، وليست أوامر تنفيذ.

## طريقة استخدام المصادر

Micro Live هو المصدر الوحيد الذي يُطلب فتحه وتجربته فعليًا. Accounting لا يملك رابط تشغيل مطلوبًا في هذه المراجعة؛ يقرأ الوكيل مستودعه، ويحاول تشغيله محليًا إذا كانت بيئته تسمح، ثم يصرّح صراحةً إن تعذر ذلك. Micro repository يُستخدم لفهم المنتج والاحتياجات. Accounting يُستخدم كمرجع بصري. Micro Standard v2 هو الأساس البصري الحالي الذي نراجعه ولا نعدله.

## ممنوعات المراجعة

لا تعديل، لا كود، لا Prototype جديد، لا إصلاح Prototype v0، لا Push، لا Merge، لا Palette جديدة، لا إعادة قيم قديمة، ولا اختراع سياسات مالية أو حالات منتجية غير معتمدة.

## التسليم المطلوب

يجب وضع التقرير الكامل داخل نص المحادثة نفسه، وإرفاقه أيضًا كملف Markdown قابل للتحميل. يجب فصل المؤكد عن المستنتج وعن قرار المالك، وتصنيف كل توصية إلى Standard أو Micro composition أو Product decision أو Reject/Defer.
