# شاشات Agent-03 — Rationale الموحد (لكل اتجاه: C1 / C2 / C3 / Selected)
**ملاحظة عدالة:** المحتوى والأرقام والحالات والبنية متطابقة عبر الاتجاهات (مولّدة من مصدر واحد fixtures.py) — الفروق في الجلد البصري فقط. الـrationale أدناه مشترك بنيويًا؛ ما يختلف بين الاتجاهات مذكور في جدول الجلود آخر الملف.

## 1. home.html — مشروعي الآن (الحالات: موجبة/غير مكتملة/سالبة/فارغة + قائمة الشعار)
- **سؤال المستخدم الأساسي:** «كيف وضع مشروعي؟» + «شو أول شي أعمله؟» (IX-D01).
- **البؤرة الأولى:** Business Status Hero — الرقم/الحالة عند 44px/700 داخل الحقل المهيمن الوحيد.
- **الإجراء الأساسي:** QAB «بيع» (تعبئة) داخل initial viewport عند 390×844 (فحص آلي: 302–413px).
- **غرض الكتلة اللونية:** الهيرو = إعلان الحالة (الموجبة: هوية دافئة؛ السالبة: سطح فاتح + إطار أحمر = جدية بلا اتهام؛ الناقصة: تيراكوتا + أمبر)؛ الإشارة = تينت انتباه + حافة؛ الملاحة = حبر.
- **الوصول:** شرائح الحالة بأيقونة+نص، عدّاد مقاطع (شكل+رقم)، bdi لكل المبالغ، أهداف 44-48px.
- **ما أُبقي هادئًا عمدًا:** ملخص اليوم والاستحقاقات (صفوف لا بطاقات متساوية) والنشاط الأخير (كثافة منخفضة).
- **فرضية:** هل يُقرأ العدّاد 8/10 كتقدم لا كذم (H2) — اختبار مستخدم.
- **الحالة الفارغة (H):** بطاقة تشجيع + سطر «المجهول لا يتحول إلى صفر» + إجراء واحد؛ بلا أقسام بيانات.
- **تركيب موثق (D-010):** قيم مساندة لحالتي B/C وقيم نشاط C مركّبة ثابتة عبر الاتجاهات — لا تمس المقفل.
- **قائمة الشعار (?sheet=menu):** خمسة مداخل حقيقية إلى أدواتي (IA-D03) — تركيز محصور + عودة.

## 2. sale.html — سجّل بيعًا (form/validation/success/system-error)
- **السؤال:** «أسجل بيعًا بسرعة وأفهم شو رح يصير».
- **البؤرة:** حقل المبلغ مسيطر (30px/700، لوحة أرقام، عملة مرئية).
- **الإجراء:** «سجّل البيع» — 3 لمسات فعلية (فتح/مبلغ/سجّل)؛ قيم افتراضية قابلة للتعديل.
- **معاينة الأثر:** داخلية غير معترضة، تتحدث حيًا مع الإدخال (D-213).
- **validation (I):** يعترض النقر عند ≤0 — بلا تنقل، بقاء المدخلات، تركيز الحقل، رسالة تشرح المشكلة والاسترجاع (role=alert).
- **success (G):** 25.00 → درج المحل → الكاش 161.00 (إبراز) → #142 → تراجع. ثقة نظامية (حبر + تينت Trust) لا أخضر.
- **system-error (J):** «ما تغيّر أي رقم» + المدخلات باقية + إعادة محاولة.
- **فرضية:** هل يثق المستخدم بالقيم الافتراضية دون تعديل (H5).

## 3. finance.html — المالية
- **السؤال:** «وين وصلت؟ مين عليه لي؟ شو عليّ؟».
- **البؤرة:** نتيجة الفترة بقيمة موسومة بالاكتمال (10/10).
- **الصفوف:** كاش/لي عند/عليّ/دفعات لاحقة — منفصلة (لا مقاصة)، دريل بهدف صادق (أوراق سياقية).
- **هدوء عمد:** تعبيرية Medium (3-4 نقاط طاقة)، بلا بطاقات احتفالية.
- **الوصول:** تباين مقيس، أرقام tabular.

## 4. work.html — العمل
- **السؤال:** «شو طلباتي؟ شو متأخر؟ شو جاي؟».
- **البؤرة:** الأولوية الحالية (طلب سارة المتأخر — بطاقة انتباه بحافة).
- **سكة الحالات:** اتفاق→تنفيذ→جاهز→تم التسليم + متأخر كاستثناء (شارة + لون + أيقونة).
- **هدوء عمد:** قوائم كثيفة قابلة للمسح المتسلسل.

## 5. order.html — الطلب المتأخر (التجهيز D كاملًا)
- **السؤال:** «شو صار بهالطلب؟ شو أعمل فيه؟».
- **البؤرة:** شارة متأخر + السكة عند «تنفيذ».
- **المبالغ:** متفق 75 / عربون 25 / متبقي 50 — المتبقي معلوماتي (Trust) لا خطر.
- **الإجراءات:** حدّث الحالة (يقدّم المرحلة فعليًا — عرض توضيحي موثق) + شارك مع الزبونة (ورقة صادقة).

## 6. tools.html — أدواتي
- **سؤال:** «وين أحمي بياناتي وأتحكم بإعداداتي؟».
- **المجموعات الأربع** حسب هدف المستخدم (الحماية/بياناتي/أدوات المشروع/الحساب).
- **الوضع الليلي هنا** (IA-D04 مقفل) — مبدل حصري يحفظ الثيم ويربط الروابط.
- **الوصول:** الحماية ظاهرة دائمًا حتى بإعداد غير مكتمل.

## 7. market.html — السوق
- **سؤال:** «شو رح يكون بالسوق؟ شو متاح هسا؟».
- **الصدق:** «غير متاح حاليًا» صريح + وعد مستقبلي بلا تلميح تشغيلي.
- **الإجراء الوحيد:** تسجيل اهتمام (حالة محلية صادقة).

## 8. products.html — منتجاتي وخدماتي (سياقية)
- **سؤال:** «وين قائمتي وأسعاري؟».
- **صدق المرجعية:** «لا تعني تتبع مخزون» (IA-D02).
- **الوصول:** من home/work/النماذج — ليست تبويبًا سادسًا.

## 9. more.html — المزيد (حالة QAB الموسعة)
- **سؤال:** «شو أدوات إضافية؟».
- **صدق:** الأدوات المتاحة فعليًا تعمل؛ الخارج عن النطاق موسوم بصدق. لا FAB مزدوج (IX-D03).

## ملاحظة لقطات الحالة المتوازية (D-410)
حالات النموذج لقطات متوازية من التجهيزات الثابتة وليست جلسة واحدة متطورة: النجاح (G) يمثل اللحظة بعد عملية بيع افتراضية مبنية على أساس يوم A (136→161)، بينما تعرض شاشة المالية لقطة A الثابتة (136). هذا خيار نمذجة صادق موثق — نموذج جلسة متغيرة الحالة خارج نطاق نموذج تصميم ثابت.
