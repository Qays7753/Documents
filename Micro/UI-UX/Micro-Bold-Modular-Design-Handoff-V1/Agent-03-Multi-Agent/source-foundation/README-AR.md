# دليل استخدام حزمة Micro للتصميم

هذه الحزمة هي المرجع الأساسي الذي تسلّمه إلى الـAgent المتخصص ليصمم الاتجاهات:

- C1 — Warm Bold
- C2 — Confident Bold
- C3 — Dynamic Modular

## ماذا تفعل أنت؟

1. أرسل الحزمة كاملة، ولا ترسل البرومبت وحده.
2. الصق البرومبت الموجود في `09-SPECIALIZED-VISUAL-DESIGN-AGENT-PROMPT.md`.
3. اطلب من الـAgent تأكيد قراءة جميع الملفات.
4. دعه ينفذ المسار كاملًا من Foundation Boards حتى التسليم النهائي.
5. لا ينتظر موافقة المالك بين المراحل؛ يستخدم بوابات الجودة الداخلية ويوثق نتيجتها.
6. بعد استلام الحزمة النهائية، أعد إرسالها إلى مستشار التصميم الرئيسي للمراجعة قبل اعتمادها أو نقلها للإنتاج.

## ماذا تحتوي الحزمة؟

- قراراتك المعتمدة.
- Design Direction Brief V1.
- معمارية الشاشات.
- نصوص وأرقام موحدة للمقارنة.
- قواعد اللون والخط والحركة والوصول.
- تعريف دقيق للفروقات بين C1 وC2 وC3.
- قائمة الشاشات المطلوبة.
- مصفوفة التقييم.
- البرومبت التنفيذي.
- خريطة الأدلة والقيود.
- صفحة HTML مرئية تلخص الاتجاه والمسار.
- بروتوكول رفع التسليم النهائي إلى مستودع `Documents` دون المساس بالوثائق الأخرى.

## ما الذي لا تسمح به؟

- تغيير بنية المنتج.
- إضافة تبويب سادس.
- تعديل مستودع Micro.
- دمج الاتجاهات قبل عرضها منفصلة.
- تصميم واجهات إنجليزية بدل العربية RTL.
- تثبيت Design System نهائي قبل اختيار الاتجاه.

## ما أول محطة داخلية؟

ثلاث Foundation Boards متساوية الجودة، واحدة لكل اتجاه، تشمل اللون والخط والأسطح والأيقونات والحالات وMicro Signal وQuick Action Bar وحركة نجاح العملية.

هذه المحطة ليست نهاية التنفيذ. يجب على الـAgent الاستمرار تلقائيًا حتى إكمال جميع المراحل والمخرجات المحددة في بروتوكول التنفيذ.

بعد الإكمال، يرفع الـAgent نسخة التسليم الكاملة إلى `Qays7753/Documents` وفق الملف `12-DOCUMENTS-REPOSITORY-DELIVERY.md`، عبر فرع وPull Request مستقلين.
