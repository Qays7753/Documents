## أدوات غير متاحة (محدوديات موثقة بصدق)
- **Figma MCP:** غير متصل في هذه البيئة → HTML/CSS/JS مخرج أولًا (وضع 07 المصرح). لا ملف Figma.
- **axe-core:** غير مثبت ولا يُثبّت من مصادر غير موثوقة → عُوّض بفحوصات WCAG مقيسة يدويًا/آليًا موثقة في accessibility/.
- **Lighthouse:** غير متوفر CLI في البيئة → عُوّض بفحوص أداء يدوية (أحجام الملفات: CSS ≤33KB، JS 8.8KB، إجمالي بلا خطوط 724KB — ضمن قواعد الوكيل 5 §9).
