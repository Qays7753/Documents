# Micro Bold Modular — Agent-03 (Multi-Agent Path)
## المسار الثالث المستقل: استكشاف C1/C2/C3 + التوصية المبدئية + النموذج التفاعلي

> **الصفة:** توصية مهنية معلّقة على اعتماد المالك واختبار المستخدم الحقيقي — لا ادعاء اعتماد أو اختبار لم يحدث.

**التاريخ:** 2026-09-18 · **الفرع:** `design/agent-03-multi-agent` · **الاستقلال:** لم يُقرأ أو يُستخدم أي مخرج من Agent-01/Agent-02 قبل اكتمال التقييم المستقل.

## ما الذي ستجده هنا

| المسار | المحتوى |
|---|---|
| `prototype/index.html` | **ابدأ هنا** — النموذج التفاعلي الكامل (HTML ثابت عربي RTL يعمل من file://) |
| `prototype/compare/` | مقارنة الاتجاهات الثلاثة جنبًا إلى جنب |
| `prototype/selected-direction/` | الاتجاه الموصى به (C1 + استعارات موثقة) + `design-system.html` |
| `foundations/` | لوحات أساس الثلاثة (ذاتية الاحتواء بجداول تباين مقيسة) |
| `screenshots/` | 106 لقطات أدلة (حالات × أوضاع × مقاسات × تكبير) |
| `pdf/` | عرض التسليم PDF (12 قسمًا) |
| `exports/` | PNG + PDF + JSON جاهزة للمراجعة |
| `tokens/` | أدلة التباين المقيسة Light+Dark لكل اتجاه |
| `accessibility/` | تقرير 97/97 فحصًا آليًا + دليل RTL/الوصول |
| `research/subagents/` | **تقارير الوكلاء الخمسة** (4 جولات لكل وكيل) |
| `orchestration/` | التخليص البحثي + سجل القرارات (49) + سجل التعارضات + المراجعة الختامية |
| `reports/` | الامتثال، الروبريك والتوصية، البوابات، القرارات المفتوحة، سجل الأدوات |
| `design-source/` | مصادر التصميم القابلة لإعادة التوليد (scripts/ مرآة) |

## طريقة التشغيل

افتح `prototype/index.html` في أي متصفح حديث (نقر مزدوج — بلا إنترنت ولا تثبيت). التفاصيل الكاملة في `prototype/README.md`.

## الخلاصة التنفيذية

- **ثلاثة اتجاهات بجودة متساوية** (27 شاشة بمحتوى متطابق — عدالة المقارنة بالبناء).
- **الروبريك الموزون:** C1 Warm Bold أولًا (84.2%) ثم C3 (82.8%) ثم C2 (80.3%) — لا فشل في بوابات الرفع.
- **أربع جولات نقد** بخمسة وكلاء حقيقيين أنتجت 49 قرارًا موثقًا وإصلاحات مقيسة (97/97 فحصًا آليًا).
- **كل أزواج التباين مقيسة** نهاريًا وليليًا — لا زوج فاشل.
- **القرارات المعلقة للمالك** في `reports/open-decisions.md`.
