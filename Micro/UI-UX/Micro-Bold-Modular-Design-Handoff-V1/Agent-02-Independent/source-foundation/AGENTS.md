## Allowed changes

- Design sources and exports.
- Isolated prototypes under `prototype/`.
- Evidence, audits, and reports.
- Candidate tokens and implementation-transfer documentation.

## Forbidden changes

- Any change to the Micro production repository.
- Production deployment.
- A sixth navigation tab.
- Presenting incomplete financial data as zero, profit, or loss.
- Claiming user research, owner approval, accessibility compliance, or test passage without evidence.
- Force-pushing or deleting prior design evidence.

## Definition of done

All gates pass; all required screens and states exist; C1/C2/C3 are fairly evaluated; one direction is provisionally recommended and refined; accessibility and RTL evidence is included; a prototype or motion storyboard is available; final reports and a reproducible source manifest are committed.
