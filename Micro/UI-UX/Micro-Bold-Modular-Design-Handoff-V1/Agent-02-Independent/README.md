# Micro Bold Modular — التنفيذ المستقل للـAgent الثاني
## Agent 02 — Independent Implementation

تنفيذ كامل ومستقل لمسار **Micro Bold Modular Design Direction** وفق المستودع المرجعي
`Micro-Bold-Modular-Design-Handoff-V1` @ `main` (6688845)، دون الاطلاع على مخرجات الـAgent الأول
ودون المساس بأي مسار يخصه.

> **الحالة:** توصية خبير مبدئية بانتظار اعتماد المالك واختبار مستخدم حقيقي — ليست اعتمادًا نهائيًا.

## أبرز النتائج

| البند | النتيجة |
|---|---|
| الاتجاه الموصى به مبدئيًا | **C3 — Dynamic Modular** (4.57/5) ثم C1 ‏(4.46) ثم C2 ‏(4.25) |
| التباين WCAG 2.2 | **248/248** زوجًا مقاسًا آليًا (فاتح+داكن × كل الأدوار) |
| axe-core | **0 مخالفات** · 1005 فحص ناجح · 27 صفحة |
| Lighthouse | **Accessibility 100/100** ×3 اتجاهات (Best Practices 100) |
| سلامة التخطيط | **18/18** — لا تمرير أفقي عند 320px مع نص 200% · أهداف ≥44px · RTL كامل |
| لقطات الأدلة | **78** لقطة موثقة (20 حالة × 3 اتجاهات + 11 للمطوَّر + لوحات ومقارنة) |

## كيف تشغّل النموذج؟

```bash
# الخيار 1: افتح مباشرة
agent-runs/agent-02-independent/prototype/index.html

# الخيار 2: خادم محلي (أفضل للمقارنة المتزامنة)
cd agent-runs/agent-02-independent/prototype
python3 -m http.server 8080   # ثم http://localhost:8080
```

داخل كل اتجاه: شريط «أدوات معاينة» علوي محايد للتبديل بين Light/Dark · 320/390/430 ·
نص 100/200% · حركة كاملة/مخفضة · السيناريوهات (موجبة/غير مكتملة/سالبة/فارغة · طلب متأخر · فشل حفظ).

## بنية التسليم

| المسار | المحتوى |
|---|---|
| `prototype/` | النموذج التفاعلي الكامل: `index.html` (دخول + مقارنة متزامنة) + `c1/c2/c3/selected` + `assets/` + README تشغيل |
| `design-source/` | القالب الموحد (يضمن تطابق المحتوى حرفيًا) + لوحة الأسس + سكربتات البناء + المحتوى المساند |
| `foundations/` | أدلة لوحات الأسس المرجعية لكل اتجاه |
| `critical-screens/` · `full-directions/` | أدلة الشاشات الحرجة والمجموعة الكاملة (روابط للأدلة والأساس المنطقي لكل شاشة) |
| `selected-direction/` | توثيق الاختيار `SELECTION.md` والنسخة المطوَّرة |
| `design-system-candidate/` | نظام التصميم المرشح `SYSTEM.md` (tokens/مكونات/حالات/حركة/RTL/وصول) |
| `screenshots/` | 78 لقطة أدلة بالتسمية الموحدة |
| `pdf/` | تقرير المراجعة `report.pdf` + مصدر HTML |
| `exports/` | حزمة zip للنموذج + git bundle للفرع (نسخ احتياطية قابل للتشغيل) |
| `tokens/` | Tokens بصيغتي JSON وCSS لكل اتجاه + المتطوَّر (مصدر القياس) |
| `accessibility/` | الأدلة الستة: تباين/axe/Lighthouse/RTL/استجابة/قيود — بالبيانات الخام |
| `reports/` | الامتثال، سجل البوابات، المقارنة والتوصية، القرارات المفتوحة، سجل QA، التقرير الختامي |
| `DELIVERY-MANIFEST.md` | الجرد الكامل وطريقة التشغيل والاختبارات وروابط PRs |

## الالتزامات المحفوظة

- Fixtures A–J حرفيًا (نصوص وأرقام وتسميات وترتيب) عبر الاتجاهات الثلاثة.
- 5 تبويبات كما هي؛ منتجاتي وخدماتي سياقية؛ الداكن داخل الإعدادات.
- الحقيقة المالية فوق التفاؤل البصري؛ «نتيجة» حتى يُسمح بـ«ربح».
- المحظورات الحركية مطبقة (لا Count-up ولا Confetti ولا Bounce) وReduced Motion كامل السيادة.
- لا تعديل على مستودع الإنتاج؛ لا ادعاء اختبار مستخدم أو اعتماد مالك.
