## 2. القرارات المغلقة (LOCKED) الملزمة للتنفيذ

1. **المستخدم**: صاحب مشروع منزلي/متناهي الصغر في الأردن، خبرة مالية/رقمية محدودة–متوسطة، الهاتف هو الجهاز الأساسي.
2. **عربي أولًا + موبايل أولًا**، والشاشات المفاهيمية عربية RTL فعلية — لا تُقبل Wireframes إنجليزية.
3. **الحقيقة المالية فوق التفاؤل البصري**: غير المكتمل لا يظهر أبدًا كصفر أو ربح مؤكد. كلمة «ربح» لا تُستخدم إلا عند اكتمال البيانات؛ الافتراضي «نتيجة».
4. **التنقل السفلي = 5 وجهات**: مشروعي الآن، العمل، المالية، أدواتي، السوق. لا تبويب سادس. «منتجاتي وخدماتي» وجهة سياقية فقط.
5. **المنطقة العلوية مضغوطة**: شعار Micro يمينًا يفتح قائمة الحساب/المشروع/الإعدادات/الحماية؛ «النقل والتوصيل» و«Ask Micro» يسارًا. لا Top Bar ضخم تقليدي.
6. **الوضع الداكن داخل الإعدادات** لا في الرأس الرئيسي.
7. **Quick Action Bar هو النمط الافتراضي** (بيع، مصروف، طلب، تحصيل، المزيد) بأيقونة + نص ظاهر، دون FAB مكرر.
8. **Micro نظام مالي/تشغيلي** لا شخصية AI ولا لوحة بنكية جامدة ولا ERP كثيف ولا قالب SaaS.
9. **الاتجاه الأب**: Bold Modular Micro — C يقود التكوين، A يدفيء، B يضبط ماليًا.
10. **طاقة التعبير حسب المنطقة**: الرئيسية عالية، المالية متوسطة، السجلات والإعدادات هادئة.
11. **ممنوعات الحركة**: Confetti، Count-up، نبض متكرر، Bounce ثقيل، Parallax، وأي حركة تنجو من تفضيل Reduced Motion.
12. **تباين WCAG 2.2**: نص عادي ≥ 4.5:1، نص كبير وحدود ضوابط ≥ 3:1، وقياس كل زوج لوني تشغيلي.
13. **الهدف 44–48px** للضوابط المهمة، والحالة الحرجة نص + إشارة غير لونية دائمًا.
14. **Fixtures A–J حرفيًا** في كل الاتجاهات (النصوص، الأرقام، التسميات، الترتيب).

## 3. مناطق الاستكشاف المفتوحة

- قيم اللون النهائية لكل اتجاه (مع إلزامية القياس).
- «Brand Warm»: إبقاء/تعميق/استبدال عائلة التيراكوتا — قرار مالك.
- خلفية القاعدة: canvas دافئ متوازن مقابل أسطح محايدة أنظف — قرار مالك.
- لون الثقة: أزرق عميق أو أزرق-تيل دون الخلط مع الإيجابي المالي.
- تعبير الأيقونات (أساس Lucide أحادي العائلة) مقابل معالجة أقوى.
- لمسات الموديولات السياقية المنضبطة.
- توقيع الحركة «Success Impact» وتوقيتاته.
- بنية Micro Signal المتكررة (حالة → سبب → إجراء).

## 4. الشاشات والحالات الواجب تسليمها (لكل اتجاه)

**Phase C الكاملة (14):** الرئيسية (موجبة/غير مكتملة/سالبة) + Quick Action Bar مع حالة «المزيد» الموسعة + نموذج تسجيل بيع + نجاح البيع + نظرة المالية + نظرة العمل/الطلبات + تفاصيل الطلب المتأخر + حالة الفراغ اليومي + خطأ التحقق + خطأ النظام مع Retry + وضع داكن للرئيسية + قائمة الحساب من الشعار.
**إضافات تفاعلية مطلوبة من المالك:** تبويبات التنقل الخمسة، درجات العرض 320/390/430، نص 200%، Reduced Motion، Light/Dark، والمقارنة المتزامنة.
**Responsive Proofs:** 320/390/430 + حالة 200% نص للشاشات الحرجة.

## 5. القيود الملزمة

- نفس المحتوى والأرقام والمقاسات والحالات وبنية المعلومات بين C1/C2/C3 — بلا أي تحسين منفصل لاتجاه دون آخر.
- الحفاظ على اتجاهات منفصلة حتى اكتمال المقارنة.
- لا تعديل على مستودع الإنتاج ولا ادعاء اعتماد أو اختبار مستخدم لم يحدث.
- كل زوج لوني تشغيلي يُقاس ويوثَّق، ولا يُقرَّب فاشل إلى ناجح.
- أرقام لاتينية Tabular معزولة داخل RTL، والعملة «د.أ»، والتواريخ DD/MM/YYYY.
