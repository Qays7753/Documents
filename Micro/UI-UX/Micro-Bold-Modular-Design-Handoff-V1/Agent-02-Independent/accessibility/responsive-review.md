## 2. اختبار إجهاد النص 200% (WCAG 1.4.4)

- طريقة التطبيق: مضاعفة خط الجذر (`html[data-text="200"] { font-size: 200% }`) — قياس حقيقي وليس zoom متصفح.
- **النتيجة: لا تمرير أفقي في أي اتجاه** (أُثبت بالقياس `scrollWidth ≤ clientWidth`).
- سلوك إعادة التدفق المُصمم والمُختبر:
  - رقم البطل يتحجم عبر **Container Queries** (`clamp(28px, 11cqw, 44px)`) — يبقى بروزه كاملًا دون فيضان.
  - شريط الإجراءات والتنقل يلتفان لصفوف ثانية بدل الانضغاط.
  - صفوف المالية والطلبات تسمح بلف القيم الطويلة.
  - أعمدة أرقام البطل في C3 تنكسر لعمود واحد تلقائيًا (`auto-fit`).
- الدليل البصري: `screenshots/{C1|C2|C3}-*-08-home-text200.png`.

## 3. الحركة المخفَّضة (Reduced Motion)

- تطبيقان متوازيان:
  1. **تفضيل النظام:** `@media (prefers-reduced-motion: reduce)` يصفّر مدد كل الحركات والانتقالات في النموذج كله.
  2. **زر المعاينة/الإعدادات:** `html[data-motion="reduced"]` ينفذ الإقصاء ذاته عند تفعيله يدويًا (لأغراض التقييم والتجربة داخل النموذج).
- ما يتأثر: دخول الشاشات، شرائح الأوراق، ومضة إبراز القيمة المتأثرة (Success Impact)، غزل الحفظ، دخول الكتل المتدرج في C3.
- ما لا يتأثر (عمدًا): ألوان الحالة والإشارات غير اللونية — الفهم لا يعتمد على الحركة أصلًا.
- **لا توجد أي حركة تنجو من التفضيل** — تحقق بصري: `20-reduced-motion.png` للاتجاهات الثلاثة (شاشات ساكنة تمامًا).
