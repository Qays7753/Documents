# تشغيل النموذج التفاعلي — Micro Bold Modular (Agent 02)

## متطلبات التشغيل
- أي متصفح حديث (Chromium / Firefox / Safari / Edge). **لا خادم خلفي، لا قاعدة بيانات، لا حسابات، لا خدمات خارجية.**
- كل الخطوط مستضافة ذاتيًا داخل `assets/fonts/` (ترخيص OFL).

## التشغيل

### الخيار 1 — فتح مباشر (الأسرع)
افتح `index.html` في المتصفح. كل شيء يعمل: الاتجاهات، الأدوات، الأوراق، المقارنة المتزامنة.

### الخيار 2 — خادم محلي (موصى به للمقارنة)
```bash
cd agent-runs/agent-02-independent/prototype
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## خريطة النموذج

| المسار | ماذا تجد |
|---|---|
| `index.html` | نقطة الدخول: تعريف الاتجاهات + دخول كل اتجاه + **وضع المقارنة المتزامنة** (نفس الشاشة/الحالة/المظهر في C1+C2+C3 معًا) + تعليمات |
| `c1-warm-bold/` | نموذج C1 كاملًا + `foundations.html` (لوحة أسسه) |
| `c2-confident-bold/` | نموذج C2 كاملًا + لوحة أسسه |
| `c3-dynamic-modular/` | نموذج C3 كاملًا + لوحة أسسه |
| `selected-direction/` | الاتجاه الموصى به بعد التطوير + `design-system.html` (معرض النظام المرشح) |
| `assets/` | القالب المشترك: منطق التطبيق `app.js` + بيانات Fixtures `content.js` + CSS بنيوي + الخطوط + مقارنة `compare.js` |

## شريط أدوات المعاينة (أعلى كل اتجاه — ليس جزءًا من المنتج)

- **المظهر:** فاتح / داكن.
- **العرض:** 320 / 390 / 430 (390 هو مرجع التقييم).
- **النص:** 100% / 200% (اختبار إجهاد حقيقي للـrem).
- **الحركة:** كاملة / مخفَّضة.
- **السيناريوهات:** الوضع المالي (موجبة/غير مكتملة/سالبة/يوم فارغ) · الطلبات (طبيعي/مع طلب متأخر) · محاكاة فشل الحفظ.

## ما الذي يمكنك فعله داخل النموذج؟

1. التنقل بين التبويبات الخمسة: مشروعي الآن · العمل · المالية · أدواتي · السوق.
2. فتح قائمة الحساب من شعار Micro (يمينًا).
3. استخدام شريط الإجراءات: بيع (المسار الكامل) · مصروف · طلب · تحصيل (عروض مفاهيمية موسومة) · المزيد.
4. **مسار البيع الكامل:** أدخل مبلغًا → جرّب 0 لرؤية خطأ التحقق → سجّل 25.00 → شاهد النجاح مع «شو تغيّر» (الكاش 136→161 والمبيعات 185→210) → أبرز القيم المحدثة عند العودة للرئيسية → جرّب «تراجع».
5. تفعيل «فشل الحفظ» ثم التسجيل لرؤية خطأ النظام مع «حاول مرة ثانية».
6. تجربة الطلب المتأخر من شاشة العمل أو من انتباه الرئيسية.
7. رؤية اليوم الفارغ ورسالته الصادقة «المجهول لا يتحول إلى صفر».

## ملاحظات نزاهة

- كل الأرقام من Fixtures الملف 04؛ المسارات غير المكتملة تُظهر وسم «عرض مفاهيمي» صراحة.
- الأدوات العلوية للمعاينة فقط وتم تصميمها محايدة بعمد لتظل خارج الهوية.
