# نظام التصميم المرشح — Candidate Design System
## Selected: Dynamic Modular (مطوَّر) | Agent 02 — Independent

> حالة النظام: **مرشح مفاهيمي** ناتج عن Gate 6 — ليس نظام إنتاج نهائيًا، ولا يُنقل للإنتاج قبل اعتماد المالك للاتجاه وقرارات الهوية المفتوحة واختبار المستخدم.

## 0. الأساس النسبي

- **الأصل:** C3 — Dynamic Modular (4.57/5 في مصفوفة الملف 08).
- **استعارتان مُتحكمتان:** دفء C1 (روح A) في لحظات النجاح والإبراز عبر «الكنكة الدافئة» `--c-warm-*`؛ انضباط C2 (روح B) في سياقات القراءة عبر حدود أهدأ وتنفس أوسع.

## 1. الطبقات والأدوار اللونية

أربع طبقات فقط: `Canvas` · `Group` · `Surface` · `Overlay`. الظل الصلب (إزاحة حبر 4px) للتفاعلي حصرًا؛ البنية تُبنى بالحدود والفصل النغمي (قاعدة الملف 05).

| الدور | الاستخدام المسموح | الممنوع | المتغيرات |
|---|---|---|---|
| Brand (بنفسجي) | هوية، إنشاء/بدء، لحظات مختارة | الربح، نجاح عام، خطأ | `--c-brand-{fill,onfill,text,soft,onsoft,border}` |
| Trust (تيل) | معلومات، سياق نشط، تنقل | إيجابية مالية | `--c-trust-*` |
| Positive (أخضر) | نتيجة موجبة **مكتملة فقط** | Toast حفظ عام | `--c-positive-*` |
| Attention (كهرماني) | غير مكتمل، انتباه، مراجعة | زخرفة/تنقل | `--c-attention-*` |
| Negative (أحمر) | نتيجة سالبة، خطر، خطأ مدمّر | مصروف عادي | `--c-negative-*` |
| Warm Accent (تيراكوتا، مستعار) | ختم النجاح + ومضة إبراز القيم | هوية عامة/أزرار أساسية | `--c-warm-*` |
| Zones (تيل/صدأ/أرجواني) | لهجة شريط + تبويب لكل منطقة | أكثر من لهجة للمنطقة الواحدة | `--c-zone-{work,tools-market}-*` |

كل زوج نصي/حدودي مقاس آليًا: **248/248 ≥ WCAG 2.2** (فاتح+داكن، شامل الكنكة الدافئة بلونيها).

| الدور | العائلة | الحجم |

## 4. الحالات

| الحالة | التعبير | الإشارة غير اللونية |
|---|---|---|
| نتيجة موجبة | حقل أخضر عميق + نص أبيض | أيقونة صعود + رقاقة نصية |
| نتيجة سالبة | حقل أحمر عميق + نص أبيض | أيقونة هبوط + رقاقة |
| غير مكتملة | حقل كهرماني + شريط تقدم اكتمال | أيقطة شرطة + نص السبب + إجراء |
| متأخر | لافتة كهرمانية بحد | ساعة + «متأخر يومًا واحدًا» |
| نجاح | ختم تيراكوتا بهالة دافئة + قيم قبل→بعد | علامة + خط تحت القيمة الجديدة |
| خطأ تحقق | حد أحمر للحق + رسالة سبب وإصلاح | علامة «!» + نص |
| خطأ نظام | بطاقة حوار حمراء | أيقونة X + نص + إعادتان |

## 5. الحركة (توقيع السببية)

- **القاعدة:** الحركة تعبّر عن سببية وتتوقف كليًا مع `prefers-reduced-motion` (ولا تنجو أي حركة منه).
- اللحظات: ختم الضغط 100ms · دخول كتل متدرج 220ms بفاصل 35ms · ورقة 200ms · ختم النجاح بميل −4° + هالة 240ms · **Success Impact**: ومضة واحدة دافئة 1.6s على القيمة المتأثرة ثم تخبو.
- **الممنوعات مطبقة:** Confetti · Count-up · نبض متكرر · Bounce ثقيل · Parallax.

## 6. التركيز ولوحة المفاتيح

- `:focus-visible` = حد بنفسجي 3px بإزاحة 3px + هالة `brand-soft` — مرئي على كل الأسطح.
- الأوراق: مصايدة تركيز كاملة + إعادة التركيز للمُطلق + إغلاق بـEscape.
- رابط تخطٍّ في أول التبويب.

## 7. RTL والمحتوى المختلط

- CSS منطقية 100% (90 خاصية، صفر فيزيائية) — قابلة للانعكاس الكامل مستقبلًا.
- `.num { direction:ltr; unicode-bidi:isolate; tabular-nums }` لكل قيمة؛ العملة «د.أ» خارج العزل.
- مرايا الاتجاهية فقط (الشاحنة)؛ chevrons باتجاه القراءة.

## 8. الاستجابة

- 320/390/430 عبر Container Queries (`cqw`) للبطل + لفّ حقيقي للتنقل/QAB عند 200% نص (بلا تمرير أفقي — مثبت هندسيًا 18/18).
- Dark: انقلاب حبر مع معايرة وهج كاملة (248 زوجًا شاملة الداكن).

## 9. خريطة النقل للإنتاج (Implementation Handoff)

1. الـTokens (`tokens/selected-direction.tokens.{json,css}`) نقطة البداية للتهجير بعد الاعتماد.
2. عناصر الملف 10 المسجلة كـ`IMPLEMENTATION_HANDOFF` (حجب QAB، قيم ورقة قديمة، تحذير حفظ خاطئ، تاريخ إنجليزي، UUID) عولجت مفاهيميًا هنا ويُحل منطقها في مسار الكود.
3. أي منطقة جديدة (السوق/التوصيل) تلتزم «لهجة واحدة» وبحد أقصى 4 لهجات نشطة.
